Beyond robots.txt and llms.txt, these files help, sorted by how much they matter.

## High value

| File | Helps | Why |
|---|---|---|
| **sitemap.xml** (or a sitemap index) | SEO, AIO | Tells crawlers which URLs exist and when they changed. Keep `lastmod` accurate. |
| **IndexNow key file** (`/<key>.txt`) | SEO, GEO | Instantly pings Bing and other participating engines on updates. Bing data feeds several AI assistants. Google doesn't use IndexNow. |
| **JSON-LD structured data** | SEO, AEO, GEO | Not a standalone file, but a script in your pages. Use Organization, WebSite, Service, Article, FAQPage, BreadcrumbList, and Person for authors. Accurate entity data helps AI systems identify who you are. |
| **Markdown versions of key pages** (`/services.md`) | GEO | Clean text that LLM tools can ingest. It's what llms.txt links to. |
| **RSS/Atom feed** (`/feed.xml`) | SEO, GEO | Faster discovery of new posts, and a clean content source for aggregators and AI tools. |

## Medium value

- **Image sitemap or video sitemap:** If you use case-study visuals or videos, these help discovery in image and video search.
- **OG/Twitter share images:** They don't affect ranking, but they improve click-through when links are shared.
- **`manifest.webmanifest` and favicons:** Good site hygiene. Google also uses the favicon in results.
- **`llms-full.txt`:** The full text of key pages in one file. Optional, and mostly useful for docs-heavy sites.
- **`/.well-known/security.txt`:** A small trust signal and good practice, not a ranking factor.
- **Redirect rules** (`next.config.js` redirects): Clean 301s preserve link equity when URLs change. This is a config rather than a file you publish.
- **Search Console and Bing Webmaster verification:** Use the DNS method or a meta tag, so you don't need to host an HTML file.

## Pages that work like files

These pages often matter more than any file, especially for AEO and GEO:
- **About page and author pages:** Real names, credentials, and links to LinkedIn and other profiles. This strengthens entity signals.
- **FAQ pages:** Question-style headings with a direct answer right below them, plus FAQPage schema where it fits.
- **Case studies and original data:** The most citable content you can publish.
- **Pricing page:** AI tools get asked about pricing constantly, so a clear page gets cited.
- **Custom 404 page** with links to key sections.

## Skip these

- **ai.txt, humans.txt, ai-plugin.json:** No major engine uses them, or they're obsolete.
- **meta keywords:** Ignored.
- **Auto-generated pages for every prompt variation:** Google can treat this as scaled content abuse.

## Next.js file map

```
app/robots.ts            → robots.txt
app/sitemap.ts           → sitemap.xml
app/manifest.ts          → manifest.webmanifest
app/opengraph-image.tsx  → OG images
app/feed.xml/route.ts    → RSS feed
public/llms.txt          → llms.txt
public/<indexnow-key>.txt → IndexNow
```

For an agency site like yours, I'd start with sitemap, JSON-LD (Organization, Service, FAQPage), an RSS feed, and IndexNow. Then add case studies and an FAQ page.
